# Русский и кыргызский интерфейс

Переключатель «Кыргызча / Русский» находится в шапке на компьютере и телефоне. Выбранный язык сохраняется в `quranlearn-language`, применяется после обновления и синхронизируется между вкладками одного сайта. По умолчанию выбран русский язык.

Язык интерфейса не меняет хранящиеся имена, заметки, названия пользовательских заданий и другие введённые данные. Формы не перемонтируются при переключении, поэтому незавершённый ввод сохраняется. Внутренние коды групп, статусов и способов оплаты не переводятся.

## Добавление переводов

- Русские исходные сообщения служат ключами в `src/shared/i18n/ky.json`.
- Компоненты получают `translateText` и `locale` через `useTranslation()`. Подписка нужна для переключения без перезагрузки.
- `localizeUI()` используется только для неизменяемых описаний интерфейса, например списков статусов. Нельзя передавать туда записи из хранилища пользователей.
- Динамические сообщения используют места `{0}`, `{1}` и т. д. При переводе сохраняйте все места; их порядок можно менять.
- Форматирование дат использует выбранный язык. Даты хранения остаются в исходном формате.
- SSR и первый проход гидратации используют русский язык; сохранённый выбор применяется после подключения клиента. Это предотвращает несовпадение серверной и клиентской разметки.
- При недоступности localStorage переключение продолжает работать в текущей сессии.

## Проверка

```bash
node --test scripts/i18n.test.mjs
npm run build
npm run lint
```

Проверки покрывают места подстановки во всём словаре, динамические сообщения, неизменяемые идентификаторы, сохранение и синхронизацию языка, недоступное хранилище и кыргызские даты в браузерах без поддержки кыргызского ICU.

Для просмотра адаптации обоих языков:

```bash
cp scripts/localization-review.html public/localization-review.html
cp src/shared/i18n/ky.json public/i18n-review-messages.json
npm run dev
```

Открыть `/localization-review.html`. Кнопка проверки проходит по маршрутам на ширинах 320, 390 и 1440 px для русского и кыргызского языка. Диагностика оставшихся русских сообщений может включать пользовательские названия из демонстрационных данных; их переводить не следует. Проверочные файлы не включаются в готовую публикацию.
