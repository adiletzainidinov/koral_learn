# Настройка реального реестра

Новый маршрут: `/real-payments`. Старые экраны «Семьи» и «Поддержка» пока остаются на локальном Zustand — **не вводите там реальные платежи**.

## Подключение
1. Подтвердить Supabase-проект, принадлежащий QuranLearn. Не использовать произвольный проект из списка.
2. Создать единственную учётную запись администратора в Supabase Auth (email/password). Отключить публичную регистрацию в настройках Auth.
3. Применить SQL из `supabase/migrations/20261122_ql_real_family_payments.sql` к **подтверждённой** базе. Перед этим сделать резервную копию.
4. В Vercel для `koral-learn` установить `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`. Использовать только publishable key, **никогда service_role**.
5. Запустить сборку и проверить вход, создание семьи, запись 1000 сом, перезагрузку и вход с другого устройства. Не создавать фиктивные операции в рабочей базе: тестировать в отдельном staging-проекте.
6. Настроить резервное копирование и тест восстановления перед вводом реальных данных.

## Ограничения текущей версии
- Первая версия реестра изолирована от старых сущностей `Family`/контактов/учеников; их миграция ещё не выполнена.
- Сессия хранится только в памяти вкладки. После перезагрузки потребуется повторный вход.
- Пока не реализованы экспорт, резервное копирование, сторно платежа, статус брони без оплаты и ограничение доступа к самому маршруту до формы входа.
- Статус «оплачено» вычисляется по сумме фактических платежей и ожидаемой сумме.
- Миграция только создаёт новые таблицы, ничего не удаляет.
