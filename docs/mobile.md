# Мобильная версия QuranLearn

Основной интерфейс адаптируется к ширине экрана. Отдельное приложение или адрес для телефона не требуются.

- До 1024 px навигация открывается кнопкой в шапке. Нативный `dialog` удерживает фокус; Escape, кнопка закрытия, фон и переход по ссылке закрывают меню. При переходе на широкую версию блокировка прокрутки снимается.
- До 768 px список учеников отображается карточками. Поиск доступен сразу, фильтры на телефоне раскрываются кнопкой.
- До 640 px поля форм располагаются в одну колонку, у полей ввода шрифт 16 px, у основных кнопок высота 44 px. Посещаемость отображается вертикальными блоками со всеми статусами.
- Широкие таблицы прокручиваются внутри `.table-scroll`. Вкладки и длинные группы фильтров имеют собственную прокрутку.
- Модальные окна учитывают динамическую высоту экрана и прокручивают содержимое, сохраняя доступ к закрытию и кнопкам действий.

## Проверка

В браузере проверены 28 маршрутов на 6 ширинах (168 комбинаций): переполнений документа нет. Дополнительно проверены переход из меню, Escape, восстановление фокуса и прокрутки, поиск учеников, раскрытие фильтров и доступность кнопок модального окна.

```bash
npm ci
npm run build
npx tsc --noEmit
npm run lint
```

В исходной версии линтер сообщает о 16 ошибках и 38 предупреждениях. При адаптации новых диагностик не добавлено; сборка и проверка типов проходят.

Для ручной проверки на разных ширинах используется самостоятельная HTML-страница:

```bash
cp scripts/responsive-review.html public/mobile-review.html
npm run dev
```

Открыть `/mobile-review.html`, выбрать ширину и страницу. Кнопка «Проверить все страницы» проверяет переполнение документа на ширинах 320, 390, 430, 768, 1024 и 1440 px. Это проверка раскладки: она не заменяет проверку действий и просмотра в Safari/Chrome на настоящем телефоне. Тестовая страница не включена в публикацию.

Дополнительно проверить:

1. Меню: открытие, Escape, закрытие фоном, переход в раздел, восстановление фокуса и прокрутки.
2. Ученики: поиск, раскрытие фильтров, переход в профиль и редактирование.
3. Посещаемость: каждый статус доступен без горизонтальной прокрутки страницы.
4. Профили и формы семьи, представителя и команды; узкие экраны 320–430 px.
5. Модальные окна: длинное содержимое прокручивается, закрытие и действия доступны.
