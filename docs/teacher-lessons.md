# Уроки для устаза

Раздел `/teacher-lessons` содержит каталог. У каждого урока есть постоянный адрес `/teacher-lessons/<id>`, внешний видеоплеер YouTube и русская/кыргызская шпаргалка. В репозитории и публикации нет видео, аудио или копии ролика; сохраняются только YouTube ID и текстовые материалы. Обложка загружается с YouTube.

Первый урок: «Пять целей человека» / «Адамдын беш максаты». Это название карточки в приложении, выбранное по содержанию урока; в плеере YouTube может отображаться собственный заголовок ролика.

## Просмотр и закладки

Обязательность полного просмотра явно указана на странице. Отметка «Я полностью посмотрел(а) урок» — осознанное подтверждение самого устаза. Приложение не считает открытие страницы или переход на YouTube полным просмотром и не имитирует процент просмотра.

У каждого урока одна личная закладка: кнопка на карточке фиксирует смысловой момент, другая карточка заменяет её, повторное нажатие убирает. Переход к закладке запускает плеер с её таймкода. Закладка не утверждает, что отслеживает фактическую позицию воспроизведения.

Отметки и закладки хранятся отдельно от учеников в `quranlearn-teacher-lessons`, версия 1, в текущем браузере. Сбой или некорректное содержимое localStorage не должны ломать интерфейс. Выбор языка переводит текст, не пересоздавая плеер и не сбрасывая отметки.

## Добавление следующего урока

Добавить запись в `src/entities/teacher-lesson/model/lessons.json`:

- Уникальные `id` и `number`, YouTube ID из 11 символов, длительность в секундах.
- Заголовок, описание, язык и темы в `ru` и `ky`.
- Смысловые моменты с уникальными `id`, возрастающими таймкодами, тезисами и вопросом детям в двух языках.
- Сверить тезисы с самим видео; не переносить конспект другого урока.
- Добавить заголовок страницы в словарь `src/shared/i18n/ky.json`, чтобы переводился заголовок вкладки.

Карточка, выбор урока и маршрут добавятся из каталога автоматически. Видео загружать не нужно. Для подготовки конспекта используется фактическое содержимое нового урока; автоматического создания конспектов на сайте нет.

## Проверка

```bash
node --test scripts/teacher-lessons.test.mjs scripts/i18n.test.mjs
npm run build
```

В браузере проверить вход из бокового меню, карточку и прямой адрес урока, два языка, переход по таймкоду, внешнюю ссылку, явное подтверждение просмотра, смену/удаление закладки и восстановление после обновления. Проверить страницы на ширинах 320, 390, 768 и 1440 px.

## Результаты проверки 29 октября 2026

- Production-сборка и TypeScript проходят, ESLint изменённых компонентов — без диагностик.
- 9 проверок локализации, каталога, ссылок и восстановления данных проходят.
- В браузере: 2 страницы × 4 ширины (320, 390, 768, 1440 px) × 2 языка — 16 вариантов без горизонтального переполнения.
- Проверены пункт мобильного меню, карточка урока, мобильный план из 14 моментов, восстановление отметки просмотра и закладки после перезагрузки, замена и удаление закладки.
- Переход к закладке «Добрые дела» формирует `start=2185` в iframe и `t=2185` во внешней ссылке. Переключение языка не меняет адрес iframe.
- Плеер YouTube получил метаданные нужного ролика и длительность 3543 с, но поток в облачном браузере остался в состоянии ожидания (`currentTime=0`, `readyState=0`, без media error). Фактическое воспроизведение в этой среде не подтверждено. Прямая ссылка на YouTube доступна.
- Недоступная удалённая обложка заменяется оформленным фоном без значка сломанного изображения.
